# Rohit Kumar – Portfolio

A personal portfolio website built with HTML and CSS.

## Run locally
1. Extract the ZIP.
2. Open this folder in Visual Studio Code.
3. Open `index.html` with Live Server, or open it directly in a browser.

## Projects shown
- Personal Portfolio Website – HTML and CSS.
- Sainik School Kunjpura Website Clone – static HTML/CSS recreation. The dropdown menu is interactive; other recreated sections are static and are not fully responsive.

## Project screenshots
The `assets/project-screenshots/` folder contains screenshots captured from the actual projects and supplied for this portfolio. They are used in the Projects section as evidence of the work.

## Main files
- `index.html` – page content and structure.
- `style.css` – styling and responsive layout.
- `assets/` – portrait, resume, social icon and project screenshots.
